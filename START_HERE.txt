Q: Does this need internet?
A: NO! It works completely offline with sample data.
   (Online API mode available if you deploy it)

Q: Does this need installation?
A: NO! Just open index.html in any web browser.

Q: Can I save changes?
A: In offline mode: No (resets on refresh)
   In deployed mode: Yes (full data persistence)

Q: Which browser should I use?
A: Any modern browser: Chrome, Firefox, Safari, Edge

Q: Is the data real?
A: This is a demo with realistic sample data.
   Deploy for real project tracking.
